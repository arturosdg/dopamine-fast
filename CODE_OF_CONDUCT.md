# Code of Conduct

Dopamine Fast exists to help people use social networks intentionally. We want
the project itself to be intentional too: welcoming, focused and respectful of
people's time, privacy and agency.

## Expected behavior

- Be kind, direct and constructive.
- Critique ideas and code, never the person behind them.
- Assume good intent while remaining open to correction.
- Make space for contributors with different experience levels and backgrounds.
- Explain important trade-offs and accept that maintainers may choose a smaller
  scope.
- Respect privacy. Do not post personal information, private conversations,
  browsing data or account contents.
- Disclose security concerns without publishing exploit details before a fix is
  available.

## Project principles

Contributions should strengthen user control rather than engagement. Features
that introduce surveillance, deceptive friction, attention traps or unnecessary
data collection are outside the project's goals.

Platform-specific changes should fail safely, request the minimum permissions
needed and avoid accessing post content when a structural selector is enough.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, deliberate
misinformation, personal attacks, doxxing and sustained disruption are not
welcome. Spam, manipulative promotion and attempts to weaken user privacy or
repository security are also unacceptable.

## Scope and enforcement

This code applies in issues, pull requests, reviews, discussions and other
spaces where someone represents the project.

Maintainers may edit or remove contributions, reject work, issue a warning or
temporarily or permanently restrict participation when behavior conflicts with
these expectations. Decisions should be proportionate, documented when
appropriate and focused on protecting the community.

To report a sensitive incident, open an issue containing only a request for
private contact and no personal or confidential details. A maintainer will
arrange a private channel. Immediate threats should be reported to the relevant
local service or platform.
