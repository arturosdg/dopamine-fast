# Dopamine Fast brand assets

The application icon is an original Dopamine Fast asset created for this
project in August 2026. It combines a finite descending feed with a visible
pause and time boundary.

- `icon-source.png` is the transparent 1024 px master.
- `../public/icon-128.png` is the store and manifest icon.
- `../public/icon-34.png` is the compact browser icon.

The mark contains no social-network trademarks, text or third-party artwork.
Keep the master and both exported sizes in sync when changing it.
